# Reactive Avatar

Прозрачный оверлей поверх рабочего стола: показывает твоего персонажа с Reactive
(`reactive.fugi.tech`), который реагирует на голос, мут и т.д. в Discord — как Browser Source в OBS,
только без OBS.

## Как пользоваться

1. Запусти Discord и зайди в голосовой канал.
2. Запусти **Reactive Avatar** (`Reactive Avatar.exe`). Персонаж появится в правом нижнем углу экрана,
   значок приложения — в трее (возле часов).
3. Чтобы подвинуть: **Ctrl+Alt+M** (или клик по значку в трее). Появится фиолетовая рамка —
   тащи окно мышкой. Ещё раз **Ctrl+Alt+M** — зафиксировать. В обычном режиме клики проходят
   сквозь персонажа, так что он не мешает играм и работе.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| Ctrl+Alt+M | режим перемещения вкл/выкл |
| Ctrl+Alt+H | показать / скрыть |
| Ctrl+Alt+= / Ctrl+Alt+- | размер больше / меньше |
| Ctrl+Alt+R | перезагрузить персонажа |

Всё то же — в меню значка в трее (там же парение и полёт, прозрачность, «поверх всех окон»,
автозапуск с Windows и «Настройки…» со ссылкой, точным размером и ползунками движения).

## Парение и полёт по экрану

Персонаж умеет не просто стоять на месте:

- **Парение** — плавно покачивается вверх-вниз. Включено по умолчанию.
- **Полёт по всему экрану** — сам выбирает место на экране, медленно перелетает туда (влево-вправо,
  вверх-вниз), иногда «базируется» на одном месте несколько секунд и летит дальше.
  По умолчанию выключен.

Включить и настроить: меню значка в трее → **«Парение и полёт»** (быстрые галочки) или
**«Настройки…»** — там есть ползунки, которые действуют сразу, пока их двигаешь:

| Настройка | Что делает |
|---|---|
| Размах | насколько высоко-низко покачивается, px (0 — не качается) |
| Один цикл вверх-вниз | как быстро покачивается, сек (меньше — быстрее) |
| Скорость полёта | как быстро перелетает с места на место, px/сек |
| Как часто зависает на месте | шанс остановиться в конце перелёта, % (0 — летает без остановок) |
| Зависает не меньше / не дольше | на сколько секунд остаётся на месте |
| Смотреть в сторону полёта | в полёте персонаж поворачивается лицом по ходу движения |

Как это работает:

- Летает по рабочей области того монитора, на котором стоит (панель задач не заезжает).
- Пока включён режим перемещения (**Ctrl+Alt+M**), парение и полёт ставятся на паузу, чтобы можно
  было спокойно перетащить окно; после фиксации персонаж летает уже от нового места.
- Место, где персонаж остановился, запоминается — после перезапуска он начнёт оттуда.
- Если полёт включён, а «Поворот персонажа» стоит в «Авто», в полёте он смотрит по ходу движения
  (галочка «Смотреть в сторону полёта»); без неё — как раньше, лицом к центру экрана.

## Важно

- **Поворот:** если персонаж стоит в правой половине экрана, он разворачивается и смотрит влево, к центру;
  в левой половине — смотрит вправо. Если у твоего персонажа исходно другое направление, в трее:
  «Поворот персонажа» → «Поменять направление авто-поворота». Там же можно отключить поворот или
  отзеркалить всегда.
- Приложение каждую секунду поднимает окно наверх, а если игра меняет разрешение монитора, после
  этого возвращает персонажа на прежнее место.
- В играх персонаж виден только в режимах **«Оконный»** или **«Окно без рамки / Windowed Fullscreen»**.
  Поверх настоящего эксклюзивного полноэкранного режима (например, F11 в Minecraft Java) окна других
  программ не рисуются. Для Minecraft нужен безрамочный режим, его добавляют моды (например,
  «Borderless Window» на Modrinth).
- Если вместо персонажа крутится логотип Fugi / «waiting for Discord» — значит, Reactive не видит
  Discord: проверь, что Discord запущен и ты в голосовом канале. Если Discord спросит разрешение
  для Reactive — подтверди.
- Если нужен другой персонаж или группа — вставь другую ссылку Browser Source в «Настройки…».

## Запуск из исходников / сборка

Нужен Node.js.

```
npm install
npm start          # запустить
npm run dist       # собрать portable-версию для Windows в папку dist/
```

(Или просто двойной клик по `start.bat`.)

Готовая portable-версия запускает код не из `main.js`, а из упакованного `resources/app.asar`.
Если правишь исходники и хочешь, чтобы изменения подхватил `Reactive Avatar.exe`, пересобери архив:

```
npx @electron/asar pack <папка с main.js, preload-settings.js, settings.html, icon.png, tray.png, package.json> resources/app.asar
```

Настройки хранятся в `%APPDATA%\reactive-avatar\config.json`.
